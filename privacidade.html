Política de Privacidade

Atualizada em 30 de outubro de 2026.

O ZapJarvis é um assistente pessoal de uso privado: ele roda no computador do próprio usuário e é usado apenas por ele. Esta página descreve o que o app faz com os dados da conta Google que o usuário conecta.

Quais dados o app acessa

  • Google Agenda: a lista de agendas do usuário e os eventos delas (título, horário, local e descrição), para mostrar a agenda e para criar, alterar ou apagar eventos quando o usuário pede.
  • Endereço de e-mail da conta, só para identificar qual conta foi conectada.

Como os dados são usados

  • Somente para oferecer ao próprio usuário as funções que ele usa no app: ver a agenda, receber o resumo do dia e pedir ao assistente que crie ou ajuste eventos.
  • Para responder aos pedidos do usuário, o texto dos eventos relevantes pode ser enviado ao provedor de inteligência artificial configurado pelo próprio usuário (atualmente a DeepSeek), apenas para gerar a resposta.
  • O app nunca adiciona convidados nem envia convites ou e-mails a outras pessoas.

Onde os dados ficam

  • Os tokens de acesso ficam só no computador do usuário, cifrados pelo Windows.
  • Não há servidor do ZapJarvis: nenhum dado é enviado ao desenvolvedor nem a terceiros, a não ser o provedor de IA descrito acima.
  • Os dados não são vendidos, não são usados para publicidade e não são usados para treinar modelos de IA genéricos.

Como revogar o acesso

A qualquer momento, remova a conta no próprio app (Conectores → Google Agenda → Remover) ou revogue o acesso em myaccount.google.com/permissions. Para apagar os dados locais, basta remover a pasta de dados do app no computador.

Uso limitado

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
